# Уровень 0 — Стратегический обзор + машиночитаемый слой (подсистема A)

Дата: 2026-06-19. Проект: `C:\DirectumRX\armgov-standalone` (read-only дашборд над БД RX).

## Цель
Главный экран для ЛПР (руководитель региона/ведомства): за ~10 секунд понять «всё ли в
порядке или системный сбой». Раскладка — **hero-полоса (3 стратегических KPI) + светофор
процессов**. Заодно строит **машиночитаемый JSON-агрегат** (`/api/overview`) как общий
фундамент: его рисует дашборд и позже без изменений потребляет LLM-сводка (подсистема C).

## Метрики (определения зафиксированы)
- **Сквозная пропускная способность** = `завершённые в срок ÷ все завершённые` задачи
  (полный цикл в норматив). Задача «в срок» = Completed и НИ ОДНО её задание не закрыто
  позже своего срока (`not exists assignment где completed>deadline`).
  Цвет: ≥80 зелёный · 50–79 жёлтый · <50 красный.
- **Узкое горлышко** = пара (процесс → этап) с макс. **медианой возраста активных заданий**
  (`percentile_cont(0.5)` от `now()-created` по InProcess), + размер очереди. #1 в hero,
  топ-3 списком. Детерминированная эвристика (НЕ LLM на этом этапе).
- **Долгострои** = активные задания, просроченные **> 3 дней** (`deadline < now() - 3d`).

## Слой данных — `GET /api/overview`
Самодостаточный снимок (всё в SQL, SELECT-only):
```
{
  generatedAt,
  region: {
    throughput: {pct, onTimeTotal, completedTotal, color},
    bottleneck: {process, processKey, stage, medianDays, queue},
    longRunners: {count, thresholdDays:3}
  },
  bottlenecksTop: [{processKey, process, stage, medianDays, queue}, ...],  // ранжир, для hero+LLM
  whatsBurning:   [{processKey, process, severity, headline}, ...],        // топ проблем
  processes: [{key,name,health,severity,throughputPct,overdue,longRunners,bottleneckStage,trend[]}, ...]
}
```

## UI главного экрана (`renderStart`)
- **Hero-полоса**: 3 карточки — Пропускная способность (% + цвет) · Главное узкое горлышко
  (процесс→этап, медиана дн, очередь) · Долгострои (число, порог >3 дн).
- **Светофор процессов**: строки — цветной индикатор severity, имя, health, узкое горлышко
  процесса, число просроченных, мини-спарклайн дисциплины. Клик → существующая модалка-сводка
  (`openProcModal`). Заменяет прежние крупные плитки.
- Дизайн-язык — `tokens.css`, офлайн SVG/CSS.
