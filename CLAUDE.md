# CLAUDE.md — АРМ руководителя (ARMGov-Dashboard)

Язык общения — русский.

Read-only веб-дашборд над БД Directum RX для первого лица: состояние процессов за 10 секунд с проваливанием до конкретного поручения. .NET 10 + `HttpListener`, без ASP.NET. Вся логика в двух файлах: `Program.cs` (бэкенд, ~123 КБ) и `index.html` (весь фронтенд, SPA на ванильном JS, ~233 КБ). Статус — рабочий прототип на одном стенде.

---

## Нерушимые правила

1. **Только `SELECT`.** Приложение никогда не пишет в БД RX. Правка, добавляющая `INSERT`/`UPDATE`/`DELETE` или DDL — ошибка, а не фича.
2. **Секретов в коде нет.** Пароль БД и токен LLM живут только в `config.json` рядом с exe (в `.gitignore`) или в env `ARMGOV_DB_PASSWORD` / `ARMGOV_LLM_TOKEN`. В браузер не возвращаются — маскируются. **Этот файл в git — не писать сюда креды.**
3. **Метрики должны сходиться друг с другом.** `FTR% + петли% ≈ 100%`; воронка сходится к итогу этапа (`завершено + в работе + просрочено + прервано = всего`); просрочка в KPI совпадает с просрочкой в блоке риска; все временные границы считаются в SQL через `now()`. Заказчик проверяет цифры одну о другую — ломать согласованность нельзя даже ради «более правильной» отдельной метрики.
4. **Уведомления исключаются из статистики.** Типы `*Notice`/`*Notification` подгружаются из `sungero_system_entitytype` при старте и вычитаются из всех метрик. Новая метрика обязана это учитывать.

## Окружение и сборка

Проверено 28.07.2026 на этой машине.

**`dotnet` не в PATH у новой сессии PowerShell**, хотя SDK 10.0.302 установлен в `C:\Program Files\dotnet`. Перед сборкой:

```bash
$env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')
```

Сборка и запуск:

```bash
dotnet build -c Release && bin\Release\net10.0\armgov-standalone.exe
```

- **Статику копирует сборка** (`armgov-standalone.csproj`: `index.html`, `tokens.css`, `logo-directum.svg`, `config.json` при наличии). Указание в README копировать `index.html` вручную устарело.
- `index.html` читается сервером **на каждый запрос** — правка фронта не требует ни пересборки, ни перезапуска, достаточно обновить страницу. Но файл должен быть обновлён в `bin\Release\net10.0\`, а не только в корне.
- Порт 5080, слушает `http://localhost:5080/`.
- Портативный бандл: `dotnet publish -c Release -r win-x64 --self-contained true -o dist`.

## Известные хрупкости

- **Идентификация процессов завязана на конкретный стенд.** Поручения и обращения опознаются по GUID-дискриминаторам, НПА — эвристикой `ilike` по тексту темы, этапы маршрута мапятся по фиксированным GUID. На другом стенде или после обновления платформы аналитика поедет. Это главный архитектурный риск, он же — основание для перехода на OData/метаданные RX в будущем.
- **Молчаливый `catch` при старте** — [Program.cs:305](Program.cs:305). Недоступная БД по логу неотличима от рабочей. Различать по строке в логе: `Notice types excluded from stats: 4` — это захардкоженный фолбэк, запрос к БД упал; `54` — реальный запрос прошёл.
- Метрики считаются на лету при каждом запросе (кэш ответов TTL 60с), индексной оптимизации нет.
- Аутентификации пользователя в дашборде нет; используется учётка БД с широкими правами. Для прода нужна отдельная read-only учётка.
- Автотестов кроме smoke нет; проект ведёт один разработчик.

## Работа с заметками Obsidian

- **Читать в UTF-8.** `Get-Content` в PowerShell 5.1 без `-Encoding utf8` превращает кириллицу в мусор и приводит к ложным выводам — так однажды получился фантомный список «битых» ссылок. Надёжнее `[IO.File]::ReadAllText()` или MCP-сервер Obsidian.
- Подключён MCP `obsidian` (`http://127.0.0.1:27123/mcp/`, Local REST API). Даёт индекс ссылок (`links`/`backlinks`/`unresolvedLinks`), JsonLogic-поиск по метаданным, точечное чтение и правку по заголовкам. HTTPS-порт 27124 не использовать — самоподписанный сертификат, Node его отклоняет.
- **Формат ссылок:** `[[полное-имя-файла|короткий текст]]`. Короткие `[[TICKET-NN]]` не резолвятся, потому что статус-эмодзи входит в имя файла; алиасы во frontmatter это **не** лечат — проверено 28.07.2026, индекс Obsidian их при разрешении ссылок не учитывает.
- Классы документов: артефакт события — `YYYY-MM-DD_...`, живой документ — без даты в имени.
