# Дизайн-гайд прототипа «Рабочий стол Directum RX»

Извлечён из мокапа `desktop-rx/`. Назначение — переписать фронт прототипа (React / remote-component
для веб-клиента RX) без потери визуала. Все значения — фактические из макета, не «примерно».

Источник правды по токенам: `:root` в `index.html`. Виджеты АРМ (`arm-widgets.css`) используют те же
токены и ничего своего в палитру не добавляют.

## 2. Сетка рабочего стола

Два независимых режима, оба должны сохраниться при переписывании:

**Колоночная (`.board`)** — гибкая, для страниц-заглушек и режима редактирования.
`.board-cols{display:flex;gap:16px;align-items:flex-start}`, `.col{flex:1;min-width:0;
display:flex;flex-direction:column;gap:16px}`. Ниже 900px — в одну колонку.

**12-колоночная (`.cfgw-grid`)** — основная для собранной панели.
`grid-template-columns:repeat(12,minmax(0,1fr)); column-gap:16px; row-gap:0;
grid-auto-rows:8px; align-items:start`, вертикальный ритм даёт `>* {margin-bottom:16px}`.
Ширина карточки — `cw` в единицах колонок (`grid-column: span cw`), высота — опционально
`h` в пикселях через span по 8px-рядам. Карточка с фиксированной высотой:
`display:flex;flex-direction:column;overflow:hidden`, тело `flex:1;min-height:0;overflow:auto`.

Раскладка первого экрана в мокапе: `5+7` (Входящие + KPI АРМ), затем `7` (мои поручения),
затем `12` и `12` (сотрудники, своевременность). Виджет сотрудников внутри себя —
`repeat(auto-fill,minmax(238px,1fr))`.

### 3.1 Карточка виджета

```
.card        фон --card, 1px --border, radius 8, position:relative
.card-head   flex, gap 8, padding 10px 13px, border-bottom 1px #eef1f5
  .mdot      8×8 круг — цвет модуля
  .ct        13.5px bold --title, flex:1

  .ci        16px --hint, ховер --create — иконки-действия шапки
```

### 3.4 Диалог параметров (`.dcp`)

Единый шаблон для любых «Параметров виджета»:

```
.dcp-ov    fixed inset 0, rgba(20,40,70,.28), центрирование, padding 24
.dcp       белый, radius 10, max-width 620 (620/560 по содержанию), max-height 82vh, flex-column
.dcp-h     15px 18px, снизу --border; h3 15.5px --title; .x 21px --muted
.dcp-s     поиск: 10px 18px, инпут 13.5px, radius 4, фокус — граница --create
.dcp-list  прокрутка, padding 8px 10px 12px
.dcp-g     рубрика uppercase 11px/700 --hint
.dcp-it    строка: gap 11, padding 8, radius 6, прозрачная граница
           :hover #F4F8FD   .on #F2F7FE + граница --create
.dcp-cb    чекбокс 17×17, radius 3, граница --border-strong; выбран — --create
.dcp-f     футер: счётчик слева (--muted), справа .tbtn.primary «Применить» + .tbtn.ghost «Отменить»
```

Правило: лимит выбора показывается счётчиком в футере («Выбрано: 4 из 6»), недоступные
строки — `opacity .45`, попытка превысить лимит → тост, не блокировка без объяснения.

### 3.5 Модальный просмотр (`.modal`)

`radius 10`, `max-width 760`, `max-height 80vh`, шапка `15px 18px` с `border-bottom`,
тело `14px 18px` со скроллом. Закрытие: крестик, клик по подложке, `Esc` — все три обязательны.

### 3.6 Списки и статусы

Строка списка: `padding 8–9px 0`, разделитель `1px #f3f5f8`, у последней — нет.
Структура: смысловая часть `flex:1;min-width:0` → срок (фикс. ширина, выравнивание вправо)
→ статус (фикс. ширина, точка 7px + подпись).

Статус: точка `--create` / «В работе», точка `--red` / «Просрочено», срок с
`--amber` для «истекает сегодня». Прогресс-полоса — высота 5–6px, radius 3,
жёлоб `#EDEFF3`, заполнение по порогам: ≥85% `--green`, 70–84% `--amber`, <70% `--red`.

Пустое состояние: `.empty` — 13px `--hint`, `padding 44px 20px`, пунктирная граница
`--border`, radius 8, белый фон. Внутри виджета — короткая строка 12.5px `--hint`, `padding 14px 2px`.

### 3.7 Иконки

Tabler Icons 3.11.0, шрифтом: `<i class="ti ti-имя">`. Цвет наследуется от контекста,
размер задаётся `font-size`. При переписывании допустима замена на `@tabler/icons-react`
с сохранением имён.

## 4. Правила, которые нельзя потерять при переписывании

1. **Виджет — отдельный элемент, а не участок страницы.** Каждый дашборд регистрируется
   в каталоге (`CATALOG`) с `type`, `title`, `boardTitle`, `icon`, `desc` и рендерится
   в общую обёртку карточки. Никакой собственной шапки, фона и радиуса внутри виджета.
2. **Тело виджета не знает о хроме.** Рендерер возвращает только содержимое; отступы,
   заголовок, перетаскивание, удаление, «Параметры» — ответственность обёртки.
3. **Общие фильтры — сверху, локальные — внутри.** Период и охват (`period`, `scope`)
   приходят из тулбара стола и применяются ко всем виджетам сразу; фильтры конкретного
   виджета (табы «Все / Просрочено / Истекает сегодня») живут в его теле.
4. **Параметры виджета — через диалог `.dcp`,** а не инлайн-контролами в шапке.
5. **Список в виджете ограничен 5 строками** + `.w-footer-link` со счётчиком остатка;
   полный список — отдельный переход.
6. **Drill-down по строке/карточке открывает модалку** с тем же набором колонок, что
   и в виджете; цифры в модалке обязаны совпадать с цифрами виджета при том же периоде.
7. **Тема и локаль — от хоста.** Палитра берётся из CSS-переменных, подписи — из ресурсов
   локализации; хардкод цветов и русских строк в компонентах не допускается.
8. **Никаких новых цветов.** Расширение палитры — только через `:root`.
