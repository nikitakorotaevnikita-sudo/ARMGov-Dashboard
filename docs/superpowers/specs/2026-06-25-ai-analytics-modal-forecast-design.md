# Дизайн: ИИ-аналитика на кнопку (модалка) + числовой прогноз

Дата: 2026-06-25

## Проблема
Блок «🧠 ИИ-аналитика по региону» — карточка `#c-ai` вверху стартовой, которая
**на каждой загрузке** автоматически дёргает `/api/ai/summary` (LLM, ~30 сек). Это
замедляет старт и тратит вызовы модели даже когда аналитика не нужна.

## Решение

### Часть 1 — блок → кнопка + модалка
- На стартовой вместо карточки `#c-ai` — кнопка **«🧠 ИИ-аналитика»** (вверху, где был блок).
- Клик открывает модалку `aiModal` (по образцу `procModal`/`deptModal`: закрытие ✕/Esc/клик по фону).
- ИИ-сводка грузится **только при открытии** модалки (не на загрузке страницы).
  Состояние `AISUM` и функция `loadAiSummary(force)` переиспользуются — рендер в модалку.
  Кнопка «обновить» (force=1) остаётся.

### Часть 2 — числовой прогноз (в модалке, над сводкой)
- Раздел **«Прогноз (при сохранении тренда)»** — считается на клиенте из `OVR.processes[].trend`
  (помесячные `ontime`/`overdue`), без сети и без нового бэкенда. Показывается мгновенно.
- Агрегация по региону по месяцам → метрики:
  - **Пропускная способность** = `ontime / (ontime+overdue)` %.
  - **Просрочка** = `overdue` заданий/мес.
- Экстраполяция на **3 месяца** линейным трендом (МНК по последним ≤6 месяцам).
  Пропускная клампится в [0,100], просрочка ≥ 0.
- Вывод: «сейчас → через 3 мес» со стрелкой ↑/↓ + мини-спарклайн (существующий `svgStack`/sparkline)
  с пунктирным продолжением.
- Если месяцев < 2 → «недостаточно данных для прогноза».

## Структура модалки
```
🧠 ИИ-аналитика по региону            [обновить] [✕]
Прогноз (при сохранении тренда)         ← мгновенно, из данных
  Пропускная способность: 68% → ~61% ↓
  Просрочка: ~120/мес → ~140/мес ↑
  [мини-график]
Сводка ИИ (Qwen 3.6)                     ← догружается (~30с)
  <текст>
```

## Обработка ошибок
- Прогноз — чистая арифметика (без сети); мало данных → заглушка.
- ИИ-часть: loading / «ИИ недоступен: …» как сейчас.

## Не входит
- Бэкенд-эндпоинт прогноза (данные уже на клиенте).
- Прогноз по отдельным процессам (только регион); легко добавить позже.
- Изменения логики `/api/ai/summary`.

## Риски
Минимальные: переиспользуем существующую ИИ-логику и модальный паттерн; прогноз —
детерминированная арифметика. Старт страницы становится быстрее (нет авто-LLM).
