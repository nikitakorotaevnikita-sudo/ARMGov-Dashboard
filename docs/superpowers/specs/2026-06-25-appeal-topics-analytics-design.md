# Дизайн: аналитика тематик обращений граждан (страница + виджет)

Дата: 2026-06-25

## Контекст данных (Directum RX, модуль gd_citizen)
- `gd_citizen_reqquestions` — вопросы обращений: `edoc` (обращение), `question`→классификатор,
  `transferredto`→`sungero_parties_counterparty` (куда направлено).
- `gd_citizen_classifierbase` — иерархический классификатор (ТОТКОГ): `section` (раздел),
  `topic` (тема), `theme` (подтема), `question`; имена в `displayname`/`name`, код в `fullcode`
  (`раздел.тема.подтема.вопрос`).
- Объёмы: **1175 обращений, 1849 вопросов** (100% с привязкой к классификатору),
  6 разделов · 21 тема · 334 вопроса. «Куда направлено» — 38 органов, заполнено 24%.

## A. Отдельная страница «Обращения граждан — тематики»
Доступ: пункт бокового меню (под процессом «Обращения граждан») → экран `view-appeals`.
Бэкенд: один эндпоинт `GET /api/appeals/topics` (кэшируемый), считает из `gd_citizen_*`.

Блоки сверху вниз:
1. **KPI:** Всего обращений (distinct `edoc`) · Всего вопросов · Ср. вопросов на обращение ·
   Доля обращений с >1 вопросом.
2. **Тепловая карта тематик** — treemap раздел→тема: ширина колонки = доля раздела,
   внутри плитки тем по высоте = доля темы; цвет = интенсивность (доля). Клик по теме →
   список её вопросов (модалка/раскрытие).
3. **Топ вопросов** — горизонтальные бары с % (топ-15) + «Показать все 334» (модалка).
4. **Куда направлено** — распределение по органам (`transferredto`→counterparty), бары с %,
   пометка «по направленным: 438 из 1849 (24%)».
5. **Разбивка по разделам** — компактные бары с % (6 разделов).

### Эндпоинт `/api/appeals/topics` → JSON
```
{ kpi:{requests,questions,avgPerRequest,multiPct},
  sections:[{name,n,pct}],
  treemap:[{section,sectionPct, topics:[{name,n,pct}]}],
  topQuestions:[{code,name,n,pct,requests}],
  routedTo:[{name,n,pct}], routedCoverage:{routed,total,pct} }
```
Раздел = `cb.section`, тема = `cb.topic` (резолв имён join'ом classifierbase). V1 — за весь
период (фильтр периода — позже).

## B. Краткая аналитика на стартовой
Виджет **«Топ вопросов обращений граждан»**: всего обращений + топ-5 вопросов с % +
ссылка «Тематики обращений →» (открывает страницу A). Источник — тот же эндпоинт (поле
topQuestions/kpi). Размещение — компактная карточка на стартовой.

## Навигация
- Пункт меню `Тематики обращений` (ключ-экран `__appeals`) в `renderNav`, рядом с процессами.
- Также кнопка на странице процесса «Обращения граждан»: «Тематики обращений →».

## Оговорки по данным

- Имена в БД UTF-8 (в терминале сборки бьётся кодировка — в UI корректно).
